AeroSpace

i3-like tiling WM · modifier: Alt

# main mode

Alt+Enter
Open / focus Ghostty
Alt+HJKL
Focus ← ↓ ↑ → (skips floats)
Alt+Shift+HJKL
Move window ← ↓ ↑ →
Alt+-/Alt+=
Shrink / grow window
Alt+F
Maximize / restore (fullscreen)
Alt+12345
Switch to workspace 1–5
Alt+Shift+12345
Move window to workspace
Alt+Tab
Previous workspace (back-and-forth)
Alt+Shift+Tab
Focus other monitor
Alt+Shift+M
Send window to other monitor
Alt+Shift+Space
Toggle floating / tiling
Alt+Shift+C
Reload config
Alt+Shift+;
Enter service mode

# tiling & layout

Alt+/
Columns: split side by side
Alt+\
Rows: split stacked
Alt+,
Accordion layout
Alt+Ctrl+HJKL
Group window + neighbor (auto-balance)
Alt+Shift+B
Balance sizes (even out)
Alt+Shift+R
Flatten workspace to even row

after Alt + Shift + ;

Esc
Reload config & exit mode
R
Reset layout (flatten tree)

Close all windows but current
